## 用户最小指令示例

> 按债转协议 skill，用 `法久第13批.../债转文件1001.xlsx` 生成合同。  
> 一转日期 2026-10-01，二转 2026-10-02。模板用第12批。  
> SPV 资料见附件截图。

Agent 应：列清单 → 生成 → 核对 → 报告份数/笔数/是否有未决字段。

## 常见失败点

1. Excel `dimension=A1` 未 reset → 附件漏行  
2. 反担保带账号后缀未清洗 → 误判两段转让  
3. 焕然套用锋泰模板后残留锋泰地址/账号  
4. 三转误填签订日期  
5. 只改文件名未改正文编号/批次  
6. 金额字符串 `19747.5` vs `19747.50` 被当成数据错误（应规范化后再比）
