# my-project

个人项目，多端同步。

## Kimi Code 插件：法久债转 Skills

本仓库即插件根目录（`kimi.plugin.json` 在根目录），包含两个 skill：

- `debt-transfer-contracts` —— 生成债转协议 Word 合同（一转/二转/三转/补充协议）
- `debt-transfer-sms` —— 生成 FJ-债转短信上传表

安装（Kimi Code 内执行）：

```
/plugins install https://github.com/wobuaizhaochuntao/my-project
```

安装后 `/reload` 或新会话生效。更新：修改推送后，在 `/plugins` 面板选中插件按 Enter 更新。
